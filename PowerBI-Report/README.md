# FinSight Power BI Report

## Overview
This folder contains the interactive FinSight Financial Analytics report developed using Microsoft Power BI Desktop.

The report analyses financial performance for 2024 and 2025.

## Report Pages
1. FinSight Executive Dashboard
2. Revenue and Gross Profit Analysis
3. Operating Performance Analysis
4. Final Profitability Analysis
5. 2024 vs 2025 Financial Performance
6. Profit and Loss Statement

## Technical Features
- Data cleaning and transformation using Power Query.
- Star-schema data modelling.
- DAX financial calculations and measures.
- Monthly and annual financial comparisons.
- Interactive slicers and visualisations.

## Project File
`FinSight_Financial_Analytics.pbix`

Open the Power BI file using Microsoft Power BI Desktop.

## Purpose
To analyse revenue growth, cost behaviour and profitability, and provide management with actionable financial insights.
